MediaShelf for Linux — USB Copy
================================

Linux Mint quick install:

1. Open this MediaShelf-Linux folder in the file manager.
2. Right-click INSTALL.sh, choose Properties > Permissions, and allow executing
   it as a program if needed.
3. Double-click INSTALL.sh, or open a terminal here and run: ./INSTALL.sh
4. Open MediaShelf from the applications menu.

To run without installing, execute ./mediashelf from this folder.

Required packages (Linux Mint / Ubuntu):
  sudo apt install python3 python3-gi gir1.2-gtk-3.0 celluloid

MediaShelf scans your media without changing it. Its database and generated
data are saved in a "MediaShelf Data" folder beside the selected media folder.
